# 🐍 Python Quiz

> 🧠 An interactive Python quiz game designed to test your knowledge of Python programming.

---

## 📖 About The Project

**Python Quiz** is a command-line quiz application built with Python.

It contains **50 multiple-choice questions** covering Python fundamentals, including:

* Data types
* Operators
* Loops
* Functions
* Lists
* Dictionaries
* File handling
* And more!

The program provides instant feedback after each answer and calculates the final score and percentage at the end.

## 🎮 How It Works

When the program starts, you will see:

```text
🐍 Welcome to PYTHON QUIZ!
===================================

1. Start Quiz
2. Exit

Enter your option (1 / 2):
```

Choose **1** to start the quiz.

Then answer each question using:

```text
A / B / C / D
```

After every answer, the program tells you whether your answer is correct.

At the end, you will see your final score and percentage.
